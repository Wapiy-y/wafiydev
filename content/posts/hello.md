This is the first post. It is a plain markdown file in `content/posts/`, so
writing here means editing a file and pushing it.

## How it works

Add a file in `content/posts/` named `my-post.md` and start it with a small
header block:

```yaml
---
title: My post
date: 2026-10-24
summary: One line about it.
---
```

Then write the rest in markdown and commit. The site rebuilds, and the post
shows up at `/#/blog/my-post`. There is no database and no admin panel.

> Everything you see here is a file in the repo, so it is easy to back up and
> easy to read ten years from now.
